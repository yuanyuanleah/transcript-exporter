# v1.2.0 优化说明

更新日期：2026-10-16（America/Los_Angeles）。这是执行规则和文档修订，豆包环境中的成功率和速度尚未实测，不承诺“提速 10 倍”或“零风险”。

## 保留并完善的变化

- 双模式：稳妥默认，快速按需；支持用户自定义间隔，不强制先选模式。
- 连续执行：每 10 条汇报、普通失败重试一次后继续，进度告知无需用户回复。
- 逐字稿：只在存在完整转录时用 DOM，否则 web.fetch，再按可用依赖回退；短正文、缺标点、正常关键词不再误判。
- 妙记：整批 1–3 条直接执行，超过 3 条一次确认，已有批准复用。无额外首次启用审批；首次执行用一句话说明音频将上传妙记。禁止下载/上传、依赖不支持时跳过并交付已有数据。
- 断点续采：逐条缓存完整结果，输出成功后才完成；换目标从缓存补交，失败只修复失败部分。
- 飞书：修正分页参数，按视频 ID 新增或更新，保留旧记录，不自动删除或重复追加。写后优先复用返回结果，不逐条读全表。
- 本地：必需 JSON 汇总、批次标识防覆盖、分别标注失败/跳过/无口播。
- 文档同步：主文件唯一维护节奏与回退规则，参考文档引用，使用指南与更新记录同步。

## 当前边界

仓库是供豆包工作执行的 Skill 文档，不是独立采集程序。没有新增 OCR、视频解析或转写脚本；`doubao-video-extract` 属于外部可选依赖，运行时先自动确认其版本是否支持当前抖音链接，不支持时不强行执行。不因可选依赖失败阻塞基础结果交付。
